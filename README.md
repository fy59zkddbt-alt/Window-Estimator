# Window Estimator

Основа локального веб-приложения для оконного замерщика: замер → расчёт → смета → PDF.
Реализован базовый оконный замер: одно-, двух- и трёхстворчатое окно с верхней глухой фрамугой (необязательно), технический эскиз и текущая цена остекления.

## Запуск

Node.js >= 22.12 и pnpm.

```sh
pnpm install --frozen-lockfile
pnpm run dev
```

Открыть адрес из терминала, обычно http://localhost:5173.
Проверки и production-сборка:

```sh
pnpm test
pnpm run test:watch
pnpm run typecheck
pnpm run build
pnpm run preview
```

React + TypeScript + Vite; Dexie для IndexedDB; Vitest и fake-indexeddb для тестов.
Используется pnpm-lock.yaml. Документация инструментов: [Vite](https://vite.dev/guide/), [Dexie TypeScript](https://dexie.org/docs/Typescript).

## Архитектура

`domain` не зависит от React, браузера и хранилища. `application/estimate` собирает валидированный замер,
вызывает geometry и Pricing Engine, возвращает Calculation со снимком конфигурации.
`infrastructure/storage` реализует порт CalculationRepository через Dexie.
UI получает репозиторий через props из `main.tsx` и не знает формулу.
Подробные правила и инварианты: [AGENTS.md](AGENTS.md).

Существующая WindowMeasurement расширена: помещение, название, windowType single/double/triple,
общие widthMm/heightMm, material, profileId, lamination, одна плоскость с 1/2/3 нижними секциями и необязательная transom.
Section хранит widthMm и openingType; hingeSide/hardwareId существуют только для turn/tilt_turn.
Высота секций выводится из общих размеров, а не дублируется. WindowInput — вход конструктора этой же модели.
ProfileConfiguration содержит material для проверки совместимости; фурнитура проверяется у каждой активной секции и не создаёт отдельной надбавки.
BalconyMeasurement, WindowFinishMeasurement, AdditionalWork — только начальные контракты.

Geometry возвращает totalAreaM2/activeAreaM2, bounds, sections, transom и координаты обозначений открывания.
Начало координат — верхний левый угол, единицы — мм, вид из помещения.
SVG отображает готовые прямоугольники и линии; viewBox с `preserveAspectRatio="xMidYMid meet"` сохраняет единый масштаб X/Y.
Вершина поворотного треугольника указывает на петли, толстые отметки показывают сторону петель; пунктирный треугольник обозначает откидывание.

Площади в м² определяются отдельно в geometry. Pricing Engine реализует:

```text
(totalArea × basePrice
 + activeArea × basePrice × activityPercent / 100
 + totalArea × basePrice × colorPercent / 100)
 × (1 + productMarkupPercent / 100)
```

Для turn/tilt_turn активна площадь соответствующей нижней секции; fixed и фрамуга неактивны.
Фрамуга имеет всю ширину окна и собственную высоту; нижние секции имеют высоту окна минус высота фрамуги.
Промежуточные величины не округляются, totalMinor хранит итог в копейках RUB.
Отображаемые строки округляются для чтения, поэтому их сумма может отличаться от итога на копейку.
Размеры трактуются как прямоугольная площадь изделия без вычетов профиля, технологических припусков и минимальной оплачиваемой площади.

## Ручная проверка

Порядок формы: помещение → тип → общие размеры → ширины секций → открывания → профиль → фурнитура → ламинация → текущая цена → сохранить.
Цена и эскиз обновляются автоматически только для валидного ввода.

При выборе типа создаются равные глухие секции. Изменение общей ширины не перераспределяет секции:
измените их вручную или нажмите «Распределить поровну» (сохраняет открывания/фурнитуру).
При переходе к активному открыванию по умолчанию выбираются петли слева и первая совместимая фурнитура; поля доступны для изменения.
При смене материала выбираются первый совместимый профиль и фурнитура активных секций.
При включении фрамуги высоту нужно задать явно: ноль, отрицательная высота и высота >= общей запрещены.

Равные ширины вычисляются делением без округления. Сумма проверяется с машинным допуском
`8 × Number.EPSILON × max(width, sum)`; реальный размер не корректируется.
Для трети 1000 мм поля содержат полное число JS, а подписи эскиза могут округляться для чтения.
Только превышение активной площади над общей в пределах `32 × Number.EPSILON × totalAreaM2` ограничивается общей площадью после суммирования; размеры не меняются.

Демо-тарифы: 10 000 ₽/м², активность 20%, ламинация 10%/20%, наценка 15%.
Для окна 1000 × 1500 мм общая площадь 1,5 м²:

| Открывание | Ламинация | Итог |
|---|---|---:|
| fixed | нет | 17 250 ₽ |
| turn / tilt_turn | нет | 20 700 ₽ |
| turn / tilt_turn | одна сторона | 22 425 ₽ |
| turn / tilt_turn | две стороны | 24 150 ₽ |

Дополнительный пример: double, 2000 × 1800 мм, секции 700 fixed + 1300 turn,
фрамуга 300 мм, ламинация с одной стороны. Общая площадь 3,6 м², активная 1,95 м²,
итог при демо-тарифах **50 025 ₽**. Смена hingeSide или совместимой фурнитуры не меняет цену.
Для triple можно задать 500 / 700 / 900 мм при общей ширине 2100 мм и проверить реальные пропорции эскиза.

Нажать «Сохранить в браузере», обновить страницу и нажать «Загрузить сохранённый расчёт».
Должны восстановиться тип, общие размеры, секции, фрамуга, тарифы и результат. Невалидное изменение скрывает цену/эскиз и блокирует сохранение.
Хранится одна демо-запись с постоянным ID; сохранение заменяет предыдущую запись.
IndexedDB обновлена до v2: прежние single-записи автоматически мигрируют с сохранением размеров, открывания, фурнитуры и тарифов.
Для повреждённых старых записей миграция откатывается, данные не удаляются; UI сообщает об ошибке доступа/загрузки.
Тарифы включены в снимок Calculation, самостоятельного редактора/хранилища конфигурации пока нет.
Данные привязаны к origin браузера (включая порт), не синхронизируются и могут исчезнуть при очистке данных сайта.

## Вне текущего этапа

Нет CRM, backend, auth, subscriptions, payments, серверного хранения или синхронизации.
Нет balcony block/measurement, window-finish flows, дополнительных работ в цене, каталога поставщиков,
списка замеров, DocumentSettings, полноценного документа сметы и экспорта PDF. Папка application/documents резервирует границу будущего сценария.

Тесты покрывают single/double/triple, разные ширины, фрамугу, открывания и петли, совместимость фурнитуры,
границы размеров, пропорции geometry/SVG, неизменность Pricing Engine, сохранение v2 и миграцию v1 с откатом ошибок.
